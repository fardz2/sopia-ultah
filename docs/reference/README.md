# Upstream source reference

`meng-to-sketchbook-source.html` is the untouched canonical ThreeUI document supplied for the original integration. It is retained as documentary reference and is not imported, served, injected or mounted by the application.

The complete birthday application now lives in native Svelte 5 components under `src/lib/birthday/`, coordinated by `src/lib/BirthdaySketchbookView.svelte`. Legacy frame wrappers and public runtime documents were backed up outside the project before retirement.
